# 稻

中式田园像素生活 RPG，开发中。由文字版《稻间》0.12 转型而来：规则内核带了过来，画面是新做的。

现在可以在小院种七种时令作物，进屋做饭、睡觉、收拾行囊；沿溪采集，到后山采茶、捡栗子，
在渡口钓鱼，养鸡、编竹器、腌菜。村口杂货铺每天换货，茶摊能喝茶、下棋和听闲话，六位乡邻
会随时段和天气走动。册子里记录技能、特质和成就。

厨房支持一至三样食材、四种做法、两勺调料、三种刀工和掌火；也可以翻菜谱直接选“照着做”。
做好的饭菜能吃、端走、送人。天气、饥渴和行囊容量会影响一天怎么安排。

## 怎么玩

```
npm install
npm run dev      # 然后打开 http://127.0.0.1:5173/
```

想看构建后的成品：`npm start`（构建并在 http://127.0.0.1:4173/ 打开）。
`dist/` 里是纯静态文件，放到任何静态网站上都能跑；直接双击 `dist/index.html` 不行。需要单文件时运行 `npm run build:offline`，生成 `发布/稻-手机版.html`，代码、引擎和样式全部在里面，无需联网。

|        | 键鼠                          | 触屏                       |
| ------ | ----------------------------- | -------------------------- |
| 走路   | WASD 或方向键；也可以点地面   | 左下摇杆；也可以点地面     |
| 做事   | 空格或 E（对着面前的那一格）  | 右下“做”，或者直接点那一格 |
| 选工具 | 1–4，或滚轮、Q、R，或点工具栏 | 点工具栏                   |
| 点菜地 | 走过去并做当下该做的那一步    | 同左，工具会自动换成合适的 |
| 照料地 | 对着长草、生虫的地，点“田地”  | 直接点那格地               |
| 过夜   | 进屋后对着床做事              | 进屋后点床                 |

手机和平板上一律横屏：竖着拿的时候画面会自己转过来，把手机横过来玩就行。

进度自动存在浏览器里。在“行囊 → 进度与玩法”可以导出进度 JSON，再在另一份 HTML 里导入。
导入前会检查格式并显示游戏日数，确认后才替换；浏览器中的旧进度另留一份备份。无法读取的旧档
不会被临时体验局覆盖。手记面板最下面可以重新开始。

手机使用：把 `稻-手机版.html` 下载到手机，用能够运行网页脚本的浏览器打开并横屏游玩。
部分手机的“文件”预览、聊天软件预览不会运行游戏；这种情况下需改用浏览器/HTML 查看器打开，
或将普通 `dist/` 部署为网页。已验证 Chrome 触屏模拟和离线 file://，未实测 Android、iOS 真机。
换浏览器、移动或改名 HTML 文件之前，请先导出进度，文件页的本地存储并不在所有设备上通用。

## 工程结构

```
src/kernel/    内核：命令事务、规则事件、计算管道、数据校验（取自《稻间》0.12）
src/content/   数据：日历、作物、人物、台词、地图
src/sim/       规则插件
src/port/      端口：画面和规则之间唯一的门，含存档格式
src/art/       用程序画的像素素材
src/platform/  运行环境的差异（现在只有浏览器）
src/shell/     输入意图、界面状态
src/world/     像素世界（Phaser）
src/panels/    界面面板（DOM）
src/app/       启动与组装
tests/         按 L0–L5 分层的测试
tools/         测试运行器、素材预览、样本存档
```

分层规则、改动该放哪儿、怎么写规则插件，见 [AGENTS.md](AGENTS.md)。测试怎么分层、怎么加，见 [TESTING.md](TESTING.md)。

## 现在的状态

- 画面是程序画的第一版，方向是清新淡彩的中式田园；它是可以整张替换的：每张图按名字登记在 `src/art/index.js`。
- M1–M6 已完成。请托、赴约、节令、宴席和人物故事还未移植；家庭、传承也未实现。时间、数值和经济尚未做长期平衡。
- 设备适配做了键鼠和触屏（移动端强制横屏）；手柄、桌面壳、其他平台留了位置，还没有做。
