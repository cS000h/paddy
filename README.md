# 稻

中式田园像素生活 RPG，开发中。由文字版《稻间》0.12 转型而来：规则内核带了过来，画面是新做的。

现在能玩到的是一个小院：亲手锄地、播种、浇水、收菜；和石伯、桂嫂打招呼，送一把自己种的菜，
第二天收到回礼；把菜放进院门边的收菜筐，托阿满卖掉、捎种子回来。

## 怎么玩

```
npm install
npm run dev      # 然后打开 http://127.0.0.1:5173/
```

想看构建后的成品：`npm start`（构建并在 http://127.0.0.1:4173/ 打开）。
`dist/` 里是纯静态文件，放到任何静态网站上都能跑；直接双击 `dist/index.html` 不行，浏览器不允许。

|        | 键鼠                          | 触屏                       |
| ------ | ----------------------------- | -------------------------- |
| 走路   | WASD 或方向键；也可以点地面   | 左下摇杆；也可以点地面     |
| 做事   | 空格或 E（对着面前的那一格）  | 右下“做”，或者直接点那一格 |
| 选工具 | 1–4，或滚轮、Q、R，或点工具栏 | 点工具栏                   |
| 点菜地 | 走过去并做当下该做的那一步    | 同左，工具会自动换成合适的 |
| 过夜   | 对着自家的门做事              | 点自家的门                 |

手机和平板上一律横屏：竖着拿的时候画面会自己转过来，把手机横过来玩就行。

进度自动存在浏览器里。手记面板最下面可以重新开始。

## 工程结构

```
src/kernel/    内核：命令事务、规则事件、计算管道、数据校验（取自《稻间》0.12）
src/content/   数据：日历、作物、人物、台词、地图
src/sim/       规则插件
src/port/      端口：画面和规则之间唯一的门，含存档格式
src/art/       用程序画的像素素材
src/platform/  运行环境的差异（现在只有浏览器）
src/shell/     输入意图、界面状态
src/world/     像素世界（Phaser）
src/panels/    界面面板（DOM）
src/app/       启动与组装
tests/         按 L0–L5 分层的测试
tools/         测试运行器、素材预览、样本存档
```

分层规则、改动该放哪儿、怎么写规则插件，见 [AGENTS.md](AGENTS.md)。测试怎么分层、怎么加，见 [TESTING.md](TESTING.md)。

## 现在的状态

- 画面是程序画的第一版，方向是清新淡彩的中式田园；它是可以整张替换的：每张图按名字登记在 `src/art/index.js`。
- 时间、数值、经济都是占位，没有做平衡。季节、天气、屋内、做饭、家庭和传承都还没有。
- 设备适配做了键鼠和触屏（移动端强制横屏）；手柄、桌面壳、其他平台留了位置，还没有做。
