# 《稻》执行方案

> 定稿日期：2026-11-14。这份方案取代此前“先打磨画面和手感”的顺序。
> 状态写在每个里程碑的标题后面，做完一个改一个。

## 为什么这么排

现在只能种田，玩起来单薄。《稻间》0.12 里已经有一整套做过、测过、写好文字的玩法：做饭、找食材、
天气、集市、乡邻、请托、留饭、宴席、节令、小案，还有技能和特质。这一轮的目标是**把它们尽可能
搬进像素世界**，再补上 0.12 没有的成就，让玩家每天有好几件不一样的事可做、有东西可攒。

画面不单独排期：每搬进一种玩法，就把它要用的物件、图标和动效一起做了。

## 搬的时候守住的几条

1. **0.12 的代码就是规格。** 源文件在 `../01_稻间_开发中/src/village/`（只读，不改它）。数值、
   判定、给玩家看的文字尽量原样带过来；要改的地方在提交说明里写明改了什么、为什么。
2. **按“人”和“户”来存。** 0.12 默认只有一个主角，体力、饥饿、行囊都是单份的。搬过来时，
   属于人的（体力、饥渴、心情、技能、特质、身上带的东西）放在这个人名下，属于家的（存粮、钱、
   鸡窝、菜谱）放在这一户名下。规则不许写死“主角”。
3. **菜单变成地方。** 0.12 里“在某个地点点一个按钮”的事，在这里都要有一个走得到的东西：
   灶台、水井、鸡窝、采集点、柜台、茶桌、钓点。点它或走到跟前按“做”，才开始。
4. **已知的毛病不要一起搬来。** 0.12 确认过的几处问题（见本文末尾）在移植时直接按修好的写。
5. **两种设备都要能用。** 每个新面板在桌面和手机横屏（矮屏）下都要放得下、点得准；
   需要精细操作的小游戏（钓鱼、火候）要同时支持键盘和手指。
6. **每个里程碑走同一套步骤**：规则插件和 L2 测试 → 端口清单（L3）→ 世界里的物件和位置 →
   面板 → 素材 → 浏览器冒烟（L5）→ 更新 `TESTING.md` → 提交。规则行为变了就更新 L4 的基线。

## 里程碑

### M1　身体与行囊（待做）

吃和喝要成为每天都得安排的事，后面的做饭和找食材才有意义。

- 搬：`core.js` 里的饥饿、心情和变化流水，`teahouse.js` 的口渴与喝水，`pantry.js` 的全部物品
  （时令、性味、风味标签），`pack.js` 的随身行囊（6 格，家里另有存放）。
- 世界：水井、溪边能喝水；院里有放东西的地方（存取）；物品要有图标。
- 面板：体力旁边加饥、渴、心情；行囊面板（带什么出门）；能直接吃生的东西。
- 完成：饿着、渴着干活更费体力、心情下降；吃喝能补回来；行囊满了有提示；有规则测试。

### M2　灶台做饭（待做）

- 搬：`cooking.js`（一到三样食材加煮、炒、烤、拌；按性味和风味算出这道菜的好处；时令菜；
  有名字的菜谱和菜谱册），柴火，`larder.js` 里会放坏的东西可以放到 M5 之后。
- 世界：檐下的灶台；做好的菜能端着走、能吃、能送人（送菜看对方口味，接上现有的回礼）。
- 面板：做饭面板（选食材和做法，先看到会做出什么）；菜谱册。
- 完成：只用自己种的和买的东西能做出一顿饭并吃掉；预览说的和实际做出来的一致；
  用几道 0.12 的菜做对照测试，结果相同。

### M3　找食材（待做）

- 搬：`daily.js` 的溪边采集、劈柴、歇息，`outskirts.js` 的钓鱼（带时机小游戏）、
  竹笋、蘑菇、板栗、采茶，`homestead.js` 的鸡窝、编竹器、腌菜和在家的夜晚。
- 世界：地图上的采集点（溪边野菜、竹林的笋、林边的柴和蘑菇），每天刷新，受天气和季节影响；
  溪边的钓点；院里的鸡窝。暂时没有后山的，先放在现有地图能到的地方，M6 再挪。
- 完成：一天可以完全靠找来的东西做一顿饭；钓鱼在键盘和触屏上都能玩。

### M4　成长：技能、特质、成就（待做）

- 搬：`growth.js` 的六项技能（农事、厨艺、采集、人情、看天、手艺）和逐级的好处、
  十二个特质（序章得来的六个、做出来的六个）。好处都用计算管道接上，不写死在别的插件里。
- 新增：**成就**。0.12 没有。做成一张登记表（听到哪件事、数到多少算达成），
  达成时在画面上盖一个印；先做二三十个，覆盖种、做、找、送、过节这几类。
- 新增：一段简短的开局选择，决定最初的两个特质（0.12 的序章是文字的，这里先做成几句话加选项）。
- 面板：一本册子，分页看技能、特质、成就；做事前的提示里写明哪些特质和技能在起作用。
- 完成：做事会涨经验、升级有提示、特质会在条件满足时得到、成就能达成并留在册子里。

### M5　天气与四季（待做）

- 搬：`weather.js`（各季的天气、一天里的变化、预报的准头随看天技能提高），`body.js` 的体感，
  `field.js` 的全部作物和各自的季节，下雨浇地、干旱、杂草和虫。
- 日历改成 0.12 的一季十四天，节令才排得开。
- 世界：雨、雾、雪的画面；四季换色（同一套素材换调色板）。
- 完成：能看天决定今天做什么；不同季节能种的、能找的不一样。

### M6　村子：茶摊、杂货铺、渡口、后山（待做）

- 新地图和地图之间的出入口。0.12 的七个地方都要走得到：小院、菜地、溪边竹径、
  樟树茶摊、村口杂货铺、河湾渡口、后山茶园。
- 搬：`market.js`（每天的货、价钱、集日、傍晚降价），`teahouse.js` 的茶摊，
  `residents.js` 里六位村民按时段、天气、季节换地方的作息。
- 完成：阿满、小乔、老周、云姑都出现在各自的地方；能在柜台买卖。

### M7　乡邻与人情（待做）

- 搬：`residents.js` 的聊天话题、每天的心情、熟悉的几个层次、送礼的喜好，
  `social.js` 的“有人看见、有人转告”，`asks.js` 的请托，`visits.js` 的约定。
- 完成：0.12 里和村民来往的一整圈都能在这里走通。

### M8　叙事：留饭、宴席、节令、小案（待做）

- 搬：`scenes.js` 的场景写法，加一个叙事面板（宣纸挂轴，配 0.12 已有的插画）；
  然后是 `meals.js`、`banquets.js`、`festivals.js`、`cases.js`、`stories.js`、`happenings.js`、
  `roads.js`、`arcs.js`、`journey.js`。
- 分三段做：先场景引擎和留饭；再节令和宴席（大节全村聚到樟树下）；最后路上的小事、小案、人物线。
- 完成：一年里的节令按日子到来，能参与；文字和选择与 0.12 一致。

### M9　CK3 式的玩法（先出一页设计，确认后再做）

搬完之后再加 0.12 没有的东西：性情影响能选什么、成功率写明、好感的加减都带原因并会淡去、
欠着的人情、从借住到当家的阶梯。想法见 `../03_稻间_设计资料/方案文档/稻间_新方向玩法与体验_讨论稿_20261113.md`。

衣着（`wardrobe.js`）、食物放坏（`larder.js`）、模型接入（`echo.js`）、家庭与传承、桌面壳、音乐。

## 0.12 里确认过的毛病（移植时直接修好）

- 场景中途离开再进来，会重复发放已经给过的东西。做法：离开时记下进行到哪一步，当天回来接着走。
- 小案在下结论那一步可以退出重试。做法：一进到结论那一步就算试过。
- 中秋赏月只带一块月饼时，每个分享的选项都会被拒绝。做法：选项列表不要依赖刚被这一步用掉的东西。
- “敬土地”每打开一次就给一次农事经验。做法：打开场景的动作不算干活，经验在场景结束时给一次。
- 赴约的台词缺老周和云姑的。做法：补上，或者没有台词的人不发起赴约。

## 这一轮不做

家庭与传承、联网、存档互通、平衡数值。数值先照 0.12，等内容齐了再调。
