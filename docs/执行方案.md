# 《稻》执行方案

> 定稿日期：2026-11-14。这份方案取代此前“先打磨画面和手感”的顺序。
> 状态写在每个里程碑的标题后面，做完一个改一个。
> 2026-11-22：特质和剧情两块按现状重排。M7 剩下的两样并进 M8；M8 改成在世界里演，分四段；
> M9 写明已经有什么、往下怎么改。下一步从 M8 第一段开始，要定的事在「等你拿主意」一节。

## 为什么这么排

现在只能种田，玩起来单薄。《稻间》0.12 里已经有一整套做过、测过、写好文字的玩法：做饭、找食材、
天气、集市、乡邻、请托、留饭、宴席、节令、小案，还有技能和特质。这一轮的目标是**把它们尽可能
搬进像素世界**，再补上 0.12 没有的成就，让玩家每天有好几件不一样的事可做、有东西可攒。

画面不单独排期：每搬进一种玩法，就把它要用的物件、图标和动效一起做了。

## 搬的时候守住的几条

1. **0.12 的代码就是规格。** 源文件在 `../01_稻间_开发中/src/village/`（只读，不改它）。数值、
   判定、给玩家看的文字尽量原样带过来；要改的地方在提交说明里写明改了什么、为什么。
2. **按“人”和“户”来存。** 0.12 默认只有一个主角，体力、饥饿、行囊都是单份的。搬过来时，
   属于人的（体力、饥渴、心情、技能、特质、身上带的东西）放在这个人名下，属于家的（存粮、钱、
   鸡窝、菜谱）放在这一户名下。规则不许写死“主角”。
3. **菜单变成地方。** 0.12 里“在某个地点点一个按钮”的事，在这里都要有一个走得到的东西：
   灶台、水井、鸡窝、采集点、柜台、茶桌、钓点。点它或走到跟前按“做”，才开始。
4. **已知的毛病不要一起搬来。** 0.12 确认过的几处问题（见本文末尾）在移植时直接按修好的写。
5. **两种设备都要能用。** 每个新面板在桌面和手机横屏（矮屏）下都要放得下、点得准；
   需要精细操作的小游戏（钓鱼、火候）要同时支持键盘和手指。
6. **每个里程碑走同一套步骤**：规则插件和 L2 测试 → 端口清单（L3）→ 世界里的物件和位置 →
   面板 → 素材 → 浏览器冒烟（L5）→ 更新 `TESTING.md` → 提交。规则行为变了就更新 L4 的基线。

### M8　剧情：在世界里演出来（改了做法；下一步从第一段开始）

原计划把 0.12 的场景搬成一页页宣纸挂轴。2026-11-18 以后的方向是事情在世界里演：采集、做饭已经

- 说话的人头顶冒气泡，一次一两句；
- 底下两三个做法，做法就是动作：伸手扶筐、回院做饭、从布包里端出来。要走开去做的，做完回来接着演；
- 后果第二天在世界里看得见，人也记着，过些天会提起。

本轮先做能在游戏里验证的交互机制；具体剧情另行评审。

**第一段　一幕的样板（下一步）**

- 规则：照 `scenes.js` 写场景引擎。一幕是几步连成的小图，每选一次是一条命令，存档能停在半中间，
  散场时才走时辰。中途离开再回来，不重复给东西。
- 画面：气泡、底下的做法；做法可以是“去做件事再回来”（回院做饭、从布包里拿东西给人）。
- 本轮验证收菜筐查账和捎货、田间指认及过客交付。剧情首幕待另行决定。
- 说话也这么演：点人先冒一句（就用 M7 正在写的那些见面话）；要聊，再给两三个今天才有的话头；
  送东西从布包里拿。现在的说话纸不再用。
  小事、过客也换成同样的演法。
- 做法贴上性情标签，选之前看得出合不合你的性子（M9 第 1、2 条）。
- 完成：这一幕在桌面和手机横屏上从头演到尾；演到一半存档、读档接得上；第二天的痕迹在；L2、L5 有测试。

**第二段　人记得你**

- 每个人记着你帮过他什么、答应了什么没做，带着原因和日子，过些天淡掉；欠着的人情还了才消。
  他说话时会提起（“昨儿你垫筐的板子，我钉成了条凳”）。
- 有人看见、有人转告：你做事时谁在跟前谁就知道，他们路上碰见会传开。
- 请托 14 件都搬成一幕；0.12 的约 50 件遇事放进小事的池子，按地方、天气、时节、谁在场来出。
- 小事的回报少给身边风物，多给东西、痕迹和人的记性。
- 村里六个人各有性情（M9 第 3 条）。
- 完成：帮过的人会提起、会转告；请托能接、能办，误了也有人记着。

**第三段　一年的盼头：节令、留饭、宴席**

- 13 个节令按日子来：前三天有人说起，前一天自己想起要备什么，当天早上知道去哪儿，第二天还有人念叨。
  五个大节（春社、端午、中秋、冬至、除夕）全村聚到樟树下，在世界里摆开。
- 留饭：午前、傍晚路过熟人家，可能被叫进去吃饭，也可以先进灶房帮一把。
- 宴席：娶亲、满月、做寿、上梁、谢田；头一天来请，当天吃席、帮厨、随礼、带菜。
- 完成：一年里的节令按日子到来，都能参与；0.12 的文字都在。

**第四段　人物线、归处、小案**

- 六个人各三步。做完一步，这个人就变了：说的话、去的地方、村里的样子跟着变（阿满骑上了三轮车，
  小乔的招牌补上了那个字，渡口点起河灯）。之前说的“季节心愿”，劲头从这里来。
- 归处：你为什么回到爷爷的村子，五步；初到一处的几句话和见闻。开局两选也挪进世界：到村那天傍晚，
  往茶摊走还是回院子，走到哪儿就是哪种性子。
- 小案 4 件：线索要到对的地方、对的时候、问对的人；推断那一步一进去就算试过。
- 完成：六个人的三步和归处都走得通，每一步在村里留下看得见的变化。

### M9　性情与人心（CK3 式；第一版已做，往下改）

0.12 没有、要新加的：性情影响能选什么、成功率写明、好感带原因并会淡去、欠着的人情、
从借住到当家的阶梯。想法见 `../03_稻间_设计资料/方案文档/稻间_新方向玩法与体验_讨论稿_20261113.md`。

现在有的：

- 十二个特质（M4，照 0.12）：开局两选给的六个（随和、自己动手、慢热、爱热闹、独行、好问），
  做出来的六个（雨中行者、耐寒、耐暑、灶边人、早起的人、熟面孔）。各有一点好处，只会多不会少。
- 第一版（2026-11-19，Gemini，用户让先提交）：五维（农务、灶艺、手艺、交际、见识），等于本事等级加 2，
  再加特质和身边风物；身边风物 12 种（好 8 坏 4），按天倒数、写明来源；小事的检定写明成功率
  （15%–95%），每件有一个只给某个特质的做法；过客和熟人册；存档 v12。
- 第二版（同日，Gemini）：过客和小事站进村里，走到跟前才能办；存档 v13。
- 本该先出的一页设计一直没出，这一版的玩法和数值都还没定。

还缺的：

- 特质只是加成。选什么都一样，玩家不会觉得“这像我”或“这不像我”。
- 村里人不认得你的性情，也不记得你做过什么。
- 五维和本事几乎是一回事（农事和农务、厨艺和灶艺、人情和交际），玩家要看两套数。
- 只给某个特质的做法是一件一件手写的，加一个特质就得回头改所有小事。

往下怎么改（跟着 M8 各段一起做）：

1. 做法带标签（第一段）：每个做法贴一两个，比如帮衬、凑热闹、独自、动手、打听、推辞、逞强。
   性情只认标签，不再逐件手写；以后加特质，只说它喜欢哪些标签、不喜欢哪些。
2. 合不合性子（第一段）：顺着性子选，心情好一点；违着性子选，心情差一点。选之前就标出来。
   不夺走操作，也不会崩。
3. 村里人也有性情（第二段）：六个人各一两个，用的就是这十二个（比如阿满爱热闹、云姑独行）。
   和你相投的熟得快、话多；相冲的慢一些，但不翻脸。
4. 人会变（第四段）：总违着一个性子、顺着另一个，攒够了就换（独行的人老凑热闹，有一天成了爱热闹的人），
   画面落一张纸条。开局给的不再定死一辈子。
5. 做出来的六个当“根骨”：在一幕里开出特别的做法（雨中行者下大雨也能跑去帮桂嫂收床单）。
6. 数只留一层，见「等你拿主意」第 3 条。

## 0.12 里确认过的毛病（移植时直接修好）

- 场景中途离开再进来，会重复发放已经给过的东西。做法：离开时记下进行到哪一步，当天回来接着走。（M8 第一段）
- 小案在下结论那一步可以退出重试。做法：一进到结论那一步就算试过。（M8 第四段）
- 中秋赏月只带一块月饼时，每个分享的选项都会被拒绝。做法：选项列表不要依赖刚被这一步用掉的东西。（M8 第三段）
- “敬土地”每打开一次就给一次农事经验。做法：打开场景的动作不算干活，经验在场景结束时给一次。（M8 第三段，春社）
- 赴约的台词缺老周和云姑的。做法：补上，或者没有台词的人不发起赴约。（M7 已补：照两人的声口补写了）
