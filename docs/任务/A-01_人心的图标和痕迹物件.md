# A-01　人心的图标和痕迹物件

> 给 Astra。开工前先读 `AGENTS.md`，和 `docs/执行方案.md` 的 M9、「分工与交接」。
> 这张单子只画图，不接进游戏：M9 的规则还没写，接线在以后的 A-03。

## 为什么要画

M9 里村民会借钱、还钱、接济、传闲话、顺手拿。玩家靠三样东西知道发生了什么：人头顶冒的记号、
地上留下的痕迹、界面上的小图标。这张单子先把这三样画出来，规则做好后直接接上。

## 要画的

### 1. 头顶记号：加进 `src/art/emotes.js` 的 `GLYPHS`

照现有 12 种的写法：7×6 的符号，`#` 是符号的颜色，`o` 是亮的一笔，放进 13×12 的小气泡；颜色只用 `P`。

| 键        | 意思       | 要让人一眼看出的样子   |
| --------- | ---------- | ---------------------- |
| `borrow`  | 求借       | 摊开的手上一枚铜钱     |
| `repay`   | 还钱       | 两三枚叠着的铜钱       |
| `dun`     | 讨债       | 一张欠条，或敲门的手   |
| `shrug`   | 推辞、拖欠 | 摆手                   |
| `basket`  | 接济       | 盖着布的小竹篮         |
| `whisper` | 传闲话     | 手挡在嘴边，或一只耳朵 |
| `sneak`   | 顺手拿     | 悄悄伸出去的手         |

和现有的 `coin`、`anger`、`sweat` 摆在一起也要分得清。

### 2. 痕迹物件：新建 `src/art/traces.js`

每样一个函数，一格 16×16，在 `src/art/index.js` 的 `OBJECT_MAKERS` 里登记，照 `trays`、`stool` 的写法。
有两种样子的，另一种登记在 `OBJECT_LOOKS` 里，照 `table` 的 `bench` 那样：地图上写 `look: 'crossed'`
就画划掉的欠条。

| 键           | 是什么                                                      | 以后由规则摆在哪儿 |
| ------------ | ----------------------------------------------------------- | ------------------ |
| `iou`        | 欠条：折起的纸压着一块小石头；另一种样子 `crossed` 是划掉的 | 桌上、门槛边       |
| `doorBasket` | 门口的竹篮，盖着布，露出点菜或蛋                            | 院门口、家门口     |
| `coinString` | 一串铜钱                                                    | 院门口、柜台上     |
| `cashBox`    | 钱匣：`open`（开着、空了一角）和 `closed` 两种              | 杂货铺柜台         |
| `footprints` | 一串泥脚印，贴着地画，不挡路                                | 雨后的门口、柜台边 |

### 3. 界面小图标：加进 `src/art/ui-icons.js` 的 `MAKERS`

16×16，照现有图标的画法和描边。

- 六项属性：`attr_renqing` 人情、`attr_chijia` 持家、`attr_danliang` 胆量、`attr_yueli` 阅历、
  `attr_xuewen` 学问、`attr_tige` 体格；
- 心烦三档：`stress_low`、`stress_mid`、`stress_high`；
- 人情账：`debt_owe`（我欠别人）、`debt_owed`（别人欠我）、`heard`（听说的事）。

## 只许改

- `src/art/emotes.js`、`src/art/ui-icons.js`、新建的 `src/art/traces.js`、`src/art/index.js`（只加登记）。
- `tools/art-sheet.mjs`：只加一段，把这张单子的新东西导出成 `.cache/renxin.png`（放大 3 倍）。
- 一个源文件超过 400 行就拆开。

## 不许碰

- `src/kernel`、`src/sim`、`src/port`、`src/content`、`src/world`、`src/panels`、`src/app`。
- 不往地图上摆这些东西；现有图标和物件的样子不改。
- 不用 PNG 或外部图片：一律用 `Grid` 和 `P` 里的颜色画（`AGENTS.md`：素材是程序画的）。

## 验收

1. 上面列的键全都在，名字一个字不差。
2. `npm run art:sheet` 导出 `.cache/renxin.png`，新东西都在上面。
3. `npm run test:all` 全过。
4. 截图两张：`renxin.png`；七个头顶记号和原有 12 个排成一排的样子。
