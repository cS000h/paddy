# A-03a　人物页和人情账做进游戏（照二稿）

> 给 Astra。开工前在工作区里从 main 开新分支：`git checkout -b astra/A-03a main`。
> 先读 `AGENTS.md`，再看你的二稿（`../03_稻间_设计资料/方案文档/人心界面设计稿/` 里的「二稿」四张图和 README）。
> 用户看过二稿，排法定了。这张单子把它做成游戏里真的册页，数全从规则的查询里来。

## 要做的

### 1. 册子「人物」页换成二稿的左右两页

- **左页「这个人」**：
  - 人物的像素小人：放大一点，放在左上，用全身像。
  - 名字、出身、行当级，写成「一级 · 笨手庄户」这样。
  - 三枚性情，每枚上面图标（`temper_` 加性情编号），中间名字，底下那句小字。
  - 根骨天资、毛病、历练用一行小字带过。
  - 心烦用碗加读数。
- **右页「六项」**：六行，每行写图标（`attr_` 加编号）、名字、数，再画一条墨色长短条，二十为满。
  - 点一行，在下面展开明细：「底子 4　勤勉 +1　农桑庄户一级 +2　＝ 7」。
  - 同一时间只展开一行，再点一下收起。
- **身边风物**：现在人物页上的风物格子和说明（`bookMod`）留着，挪到右页六项下面，样子跟册页统一。
  二稿上没画这一块，放法你定。
- **看谁**：右上角能切换看谁。名单是「你」加上六位村民。切到村民，就用他的像素小人和他的档案。
- **心境**：人物页上不再放心境条，顶上的状态栏里已经有了。

### 2. 册子加一页「人情账」

- 左边列六位村民：名字，加上熟到哪一层（`bonds` 查询的 `known`，用 `content/talk.js` 的 `tierWord(known)` 换成说法，跟手记一样）。
- 右边是点中那个人的一张卡：像素小人、名字、身份，右上角写大字「好感 +24」，下面三行：
  - **相投相冲**：好感明细里 `id` 以 `same.`、`clash.` 开头的，和 `unseen`（莫名投缘、莫名别扭）。
  - **好感来由**：`id` 以 `why.` 开头的，按分量大的在前，最多三条。
    每条写「常来说说话　+6 · 余 9 天」；没有 `left` 的写「一直记着」。多出来的写一行「还有 N 条」。
  - **熟悉**：`id` 为 `known` 的那一条。
- 欠账和听说这两行先不画，规则还没有（M9、M8 第 8 步）。
- 页签图标：在 `ui-icons.js` 加一个 `tab_ledger`，照现有页签图标的画法。

### 3. 别的几页照常能用

本事、性情、成就、熟人四页的内容不变。册子整体换成二稿的册页样子也行，只换人物和人情账两页也行，你定；
四页要在三种尺寸下都看得清、点得到。

## 数从哪里来（都是现成的查询，不许自己算）

人物页：`game.ask('persona', id)`，`id` 不写就是玩家自己。下面是玩家选了「借口锅」「陪阿满聊」、
跟石伯说了三天话以后的样子（六项只摘了两项）：

```json
{

  "unseen": 0,
  "tempers": [
    {
      "id": "diligent",
      "name": "勤勉",
      "desc": "闲不住，干完农活心里才踏实",
      "opposite": "lazy",
      "oppositeName": "懒散"
    },
    {
      "id": "gregarious",
      "name": "热络",
      "desc": "爱扎堆说话，几天没人聊就闷",
      "opposite": "shy",
      "oppositeName": "怕生"
    }
  ],
  "line": { "id": "farmer", "lv": 1, "name": "农桑庄户", "title": "笨手庄户" },
  "innate": [],
  "coping": [],
  "stress": 0,
  "attrs": [
    {
      "id": "chijia",
      "name": "持家",
      "value": 7,
      "parts": [
        { "id": "base", "label": "底子", "delta": 4 },
        { "id": "temper.diligent", "label": "勤勉", "delta": 1 },
        { "id": "line.farmer", "label": "农桑庄户一级", "delta": 2 }
      ]
    }
  ]
}
```

`game.ask('persona', 'shi')`：别人的档案只给看玩家知道的，规则已经替你挡好了。

```json
{"id":"shi","unseen":1,
 "tempers":[{"id":"diligent","name":"勤勉",...},{"id":"honest","name":"厚道",...}],
 "line":{"id":"farmer","lv":3,"name":"农桑庄户","title":"持家好手"},
 "innate":[],"coping":null,"stress":null,
 "attrs":[{"id":"chijia","name":"持家","value":13,"parts":[{"id":"base","label":"底子","delta":4},
          {"id":"temper.diligent","label":"勤勉","delta":1},{"id":"line.farmer","label":"农桑庄户三级","delta":6},
          {"id":"unseen","label":"还看不出的","delta":2}]}]}
```

怎么读：

- 性情三格：`tempers` 先占位。玩家不满三个时，空着的写「还没定下」。别人有 `unseen` 个，就有几格写「还看不出」。
- `innate`、`coping`：`null` 写「未记」，空数组写「无」。
- 历练只有玩家自己有：`game.ask('growth').traits` 里 `owned` 为真、且不在 `content/traits.js` 的 `OLD_TRAITS` 里的那几个。
- `stress` 为 `null` 时不画心烦。碗用 `stress_low`、`stress_mid`、`stress_high`：0–39、40–69、70 以上。

人情账：`game.ask('opinion', id)` 是这个村民待玩家的好感，明细已经按分量大的排在前面：

```json
{
  "from": "shi",
  "to": "hero",
  "value": 24,
  "parts": [
    { "id": "same.diligent", "label": "都勤勉", "delta": 10 },
    { "id": "known", "label": "熟悉：熟络", "delta": 8 },
    { "id": "why.chat", "label": "常来说说话", "delta": 6, "times": 3, "left": 9 }
  ]
}
```

名单和像素小人：

- 名单用 `game.ask('bonds')`，每人有 `id`、`name`、`role`、`known`。
- 玩家的样子用 `game.ask('hero').look`，村民的用 `content/people.js` 的 `PEOPLE[id].look`。
- 小人的图在 `panels/icons.js`：现在的 `heroPortraitUrl` 只截上半身。要全身像就在这个文件里加一个函数，照它的写法来。

## 只许改

- `src/panels/book.js`、`src/panels/book.css`。新页可以拆进新文件 `src/panels/person.js`（加 `person.css` 的话，
  在 `src/app/main.js` 里照 `book.css` 的样子引进来）。每个文件不超过 400 行。
- `src/panels/icons.js`：只加全身像的函数。

- `tests/L5-browser/smoke.test.js`，和 `TESTING.md` 里 L5-01 那一行的说明。
