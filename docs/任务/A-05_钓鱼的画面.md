## 玩起来是什么样

1. 走到钓点按「做」。身上有蚯蚓时先问挂不挂：「挂蚯蚓 ×3」「不挂饵」；没有蚯蚓就直接下竿。
   钓点不再走采集的小窗（`activity`），也没有「还剩几竿」。
2. **看漂**：弹出一个看得清的水面特写（横着一条，像灶台那张画），浮漂在水上。
   - 小啄：浮漂轻轻往下一点又浮上来，0.2 秒上下。这时提竿，鱼就吓跑了。
   - 咬钩：浮漂整个沉下去，停一小会儿（0.4 到 0.9 秒）。鲤鱼不往下沉，是拖着浮漂往一边走。这时提竿，就钩上了。
   - 一直没提，或者提晚了：饵被吃了，收竿。
3. **遛鱼**：钩上以后，按住「收线」不放，线往回收；松开就放线。
   - 鱼一阵一阵往外冲。冲的时候水花大，线绷紧，竿弯下去；这时还按着，线会断。
   - 松开太久（两秒），鱼会脱钩。
   - 鱼越大，冲的回数越多、越久；小鱼一两秒就上来。
   - 画面上不写数，要看得出两样：鱼离岸多远（水下一个鱼影往岸边靠），线绷得多紧（竿弯多少，线色从墨往朱红走）。
4. **上来**：关掉特写。世界里鱼蹦出水面（照收菜那一下），头顶飘「鲫鱼 七寸」。
   - 比以前钓过的同种鱼都长：再冒「新纪录」。
   - 极品：照收菜的金环、金星、那一串响。

## 第一部分：画图（现在就能做）

**六种鱼和蚯蚓的物品图标**，16×16，只用调色板里的颜色，一眼分得开：

| 物品编号         | 名字   | 样子                       |
| ---------------- | ------ | -------------------------- |
| `fish.crucian`   | 鲫鱼   | 银灰，背高，身子短         |
| `fish.bleak`     | 白条   | 细长，银白，小             |
| `fish.carp`      | 鲤鱼   | 金褐色，鳞片显，嘴边两根须 |
| `fish.grass`     | 草鱼   | 长条，青褐色               |
| `fish.yellowcat` | 昂刺鱼 | 黄褐，扁头，几根长须       |
| `fish.mandarin`  | 鳜鱼   | 身上黑斑，大嘴，背鳍带刺   |
| `worm`           | 蚯蚓   | 一截粉褐色的小虫，盘一下   |

- 极品鱼不用另画，`fineItemIcon` 会自动描金边、点星。
- 规则合进来时，这七样会先用 Claude 拿现有「鱼」图标改色的临时图，登记在 `art/index.js` 的物品图标里。
  你把画法写好，接线时换掉那几张临时图。

**水面特写**：

- 横条，桌面大约 480×160，手机横屏最矮的时候（`tight`）至少 360×110。
- 画上水、几根芦苇，竿梢和钓线从左上角伸进来，浮漂在中间。手机上浮漂至少 24 像素高。
- 三张钓点各换一点景：院边小溪、溪边竹径、河湾渡口。
- 动作：小啄、沉漂、拖漂、提竿、断线、脱钩、出水，各一套；遛鱼时有水花和鱼影。
- 样子照现在的水墨淡彩，别做成深色。

**声音**：照 `platform/web.js` 里 `sounds` 现成的合成写法加五个：

- `nod`：小啄，很轻；
- `bite`：咬钩，沉一点；
- `reel`：收线，按着的时候一下一下地响；
- `snap`：断线；
- `splash`：出水。

咬钩时手机震一下（`platform.haptic()`）。

## 第二部分：接线（等规则合进 main）

### 查询

**`game.ask('fishing', at)`**，`at` 是站位（`scene.at()`）：

```json
{
  "spot": { "id": "river", "name": "河湾渡口", "mood": "good", "moodWord": "鱼口好" },
  "reason": null,
  "cost": { "value": 2, "parts": [] },
  "bait": [{ "item": "worm", "name": "蚯蚓", "n": 3 }],
  "bout": null,
  "records": {
    "crucian": { "name": "鲫鱼", "n": 4, "best": 7, "bestText": "七寸" }
  }
}
```

- `spot`：不在钓点时是 `null`，`reason` 写着为什么不能下竿（太累了、天黑了……）。
- `mood`：`good` 鱼口好，`fair` 一般，`spooked` 惊了（这儿刚钓上好几条，换个地方或等一等）。
  提示条写成「下竿 · 2 体力 · 鱼口好」。
- `bait`：身上带着的饵，没有就是空数组。
- `bout`：下了竿才有，样子见下。

**看漂时的 `bout`**：

```json
{
  "phase": "float",
  "float": {
    "events": [
      { "at": 1800, "kind": "nod", "dur": 220 },
      { "at": 3000, "kind": "nod", "dur": 200 },
      { "at": 4200, "kind": "bite", "dur": 650, "drag": false }
    ],
    "end": 4850
  }
}
```

- `at`、`dur`、`end` 都是毫秒，从浮漂落稳那一刻算起。
- `drag` 为 `true` 时浮漂往一边拖，不往下沉。
- 过了 `end` 还没提竿，就算没提。

**遛鱼时的 `bout`**（提竿钩上以后）：

```json
{ "phase": "fight", "fight": { "size": "big" } }
```

`size` 是 `small`、`mid`、`big`，竿弯多少、水花多大照它来。

**遛鱼的每一帧问 `game.ask('fish.fight', log, t)`**：

```json
{ "t": 1350, "distance": 62, "tension": 78, "running": true, "holding": true, "done": null }
```

- `log`：你记下的按下、松开，写成 `[[毫秒, 1]]` 表示按下、`[[毫秒, 0]]` 表示松开，从钩上那一刻算起，按时间先后排。
- `t`：现在是钩上以后第几毫秒。
- `distance`：0 到 100，100 最远，0 就到岸了。
- `tension`：0 到 100，到 100 线就断。
- `running`：鱼正在往外冲。
- `holding`：照 `log` 算，现在是不是按着。
- `done`：
  - `null`：还在遛；
  - `landed`：上来了；
  - `snap`：线断了；
  - `slack`：松开太久，脱钩了。

  一出 `done`，就把 `log` 交给 `fish.land`。

规则结算用的就是这一套，画面上看到的就是结果。每帧问一次没问题，一次用不了一毫秒。

### 命令

| 命令        | 输入                           | 什么时候                                                |
| ----------- | ------------------------------ | ------------------------------------------------------- |
| `fish.cast` | `{ at, bait: 'worm' 或 null }` | 下竿                                                    |
| `fish.hook` | `{ at, t }`                    | 看漂时提竿，`t` 是第几毫秒；到 `end` 还没提，发 `t: -1` |
| `fish.land` | `{ at, log }`                  | 遛鱼出了 `done`                                         |
| `fish.quit` | `{ at }`                       | 收竿不钓了。看漂、遛鱼时都能收，遛鱼时收就算鱼跑了      |

### 事实（在 `out.facts` 里，世界和提示条照着演）

- `fish.cast {who, spot, bait}`：下竿。
- `fish.hooked {who, size}`：钩上了。
- `fish.spooked {who, line}`：提早了，鱼吓跑了。
- `fish.missed {who, line}`：没提或者提晚了，饵被吃了。
- `fish.caught {who, item, fish, name, len, lenText, n, fine, record, first, line}`：
  - `record` 为 `true`，冒「新纪录」；
  - `fine` 为 `true`，照极品那样演；
  - `first` 为 `true`，是头一回钓到这种鱼，`line` 里会说一句它的来历。
- `fish.lost {who, why, line}`：`why` 是 `snap`（线断）或 `slack`（脱钩）。

### 手上怎么按

- 键盘：「做」的键（空格、E、回车、J）。看漂时按一下提竿；遛鱼时按住收线，松开放线。
- 手指：特写底下一个大按钮。看漂时写「提竿」，遛鱼时写「收线」，要按住。
- 鼠标：按住按钮，跟手指一样。
- 旁边一个小的「收竿」。
