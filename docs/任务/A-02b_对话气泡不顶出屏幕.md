# A-02b　对话气泡不顶出屏幕

> 给 Astra。开工前先读 `AGENTS.md`。这是一张小单子：只修气泡的位置，不加新东西。

## 毛病

手机横屏（844×390）上，村民说的话一长到三行，头顶气泡就顶出屏幕上沿：气泡的上框看不见，名字贴着屏幕边。
复现：新开一局，走到桂嫂跟前点她，「接话」→「招呼一声」→「聊聊」→「问问近况」。
Claude 的截图在主工作区的 `.cache/claude-0118/shots/topics-3-news.png`；脚本 `.cache/claude-0118/topics-bubble.mjs`
能一路点到那一步（在你的工作区里也能跑，先 `npm run test:all` 或打包一次手机版）。

## 要做成什么样

- 桌面 1280×720、手机横屏 844×390、手机竖拿（画面转过来）三种情况下，气泡整个都在屏幕里，名字和上框都看得见。
- 说话的人头顶上面放不下时，气泡改放到他脚下，尖角跟着朝上，还指着说话的人；或者文字区缩短、在气泡里上下滑。
  两种做法你挑一种，说明为什么。
- 右下角的做法按钮不被气泡挡住。

## 只许改

- `src/panels/encounter.css`、`src/panels/encounter.js`。
- `tests/L5-browser/offline.test.js`：在「点阿满预览不涨关系」那条测试里，或者新加一条，断言三行话时气泡的上沿 ≥ 0、
  下沿 ≤ 视口高，三种尺寸都查。新加测试的话，照 `TESTING.md` 的规矩登记。

## 不许碰

- 规则一侧（`src/kernel`、`src/sim`、`src/port`、`src/content`），`src/world` 里的镜头和人物位置。
- 别的面板。

## 验收

1. `npm run test:all` 全过。
2. 三种尺寸各一张截图：桂嫂说三行话的时候。
