## 背景

吃饭现在看四类：谷、菜、荤、果。前三天四类都沾到，第二天清早有「气色好」；某一类连着四天没沾，出小毛病
（发虚、上火、乏力、嘴燥）。每个人还有口味，吃到合口、忌口有反应。这些玩家现在只能从提示里猜，要一页看清。

## 要做的

在册子里加一页「食录」，页签字写「饮食」。数据全从 `game.ask('diet')` 拿：

```js
{
  groups: [{ id: 'grain', name: '谷', note: '米面薯芋' }, …菜、荤（肉蛋鱼豆）、果],
  days: [{ day, grain, veg, meat, fruit }, …], // 前天、昨天、今天，各类吃了几回
  states: [{ id, name, kind: 'good' | 'bad', desc }], // 眼下挂着的气色好、小毛病
  tasted: 23, // 吃过多少道不同的菜
  palate: { likes: ['清淡', '嗜辣'], dislikes: ['怕腥'] }, // 自己的口味
  villagers: [{ id, name, known, likes, dislikes }], // known 为假时 likes、dislikes 是空的
}
```

吃腻了的菜从 `game.ask('kitchen', at)` 里拿不到，这一版不做那一格。

1. **近三日吃食**：四类各一行，前天、昨天、今天三格，吃了几回画几粒（最多画 3 粒，多了也是 3 粒）。
   每类名字底下一行小字照 `note`（「荤」那格写「肉蛋鱼豆」，免得玩家以为吃豆腐涨荤是出错）。
   一类三天都空着的，那一行淡一点。
2. **眼下**：`states` 一样一条，好的青绿、坏的暖褐，配色照身边风物（`modifiers`）的写法。点开看 `desc`。
   没有的时候不写这一块。
3. **我的口味**：「爱吃」「忌口」各一行，照 `palate`。都空着写「什么都吃得下」。
4. **乡邻爱吃**：六位村民一人一行，名字加爱吃、忌口。`known` 为假的写
   「还不算熟络，摸不清他平时爱吃哪一口。」（「他」照人写「他」「她」看人物设定；拿不准就写「这位」）
5. 底下一行小字：「吃过 N 道菜」。
6. 一顿饭都没吃过（三天全空，`tasted` 为 0）：整页只写「灶火才刚生起，这几日还没正经吃过什么。」
